# Approved product scope

ProgressiveStages 3.1.0 separates structure entry gates from protection rules. One progression stage can unlock entry while a separate manually granted or unobtainable stage continues blocking placement. Configuration includes an entry allowance and numeric priorities with compatible defaults.

Issue 57 is addressed through focused changes to the existing editor. Use plain language, concrete configuration help and actions near graph nodes. Retain advanced configuration and source editing. A complete editor rewrite and unrelated feature expansion are excluded.

Fresh generated defaults and newly created stages do not restrict essential movement. Existing administrator configurations are preserved, and movement restrictions remain available through explicit configuration.

The in game stages menu includes guidance to next stages. Pack authors can supply unlock instructions, next steps and locations through custom editor fields. Guidance respects player visibility and progression branches and does not invent objectives or claim an externally granted stage is instantly unlockable.

Completion includes version 3.1.0 publication to the established mod platforms and the updated existing web editor. Repository evidence identifies that editor as the UI served through `/pstages editor`, with assets bundled in the JAR. No separate public website or new hosting provider is specified.
