The following checks used the ProgressiveStages Phase 002 candidate, Minecraft
`1.21.1`, NeoForge `21.1.219`, Java `21`, and the artifact identities above.

| Cell | Result | Evidence |
|-----|-----|-----|

| JEI stage-change refresh | Passed real singleplayer workflow | With EMI absent, revoking `showcase:warrior` hid `minecraft:diamond_sword` in JEI. combination. Full in-world viewer interaction remains a manual follow-up at the final release gate.
