# ProgressiveStages 3.0.5 acceptance record

This record tracks the merged 3.0.5 candidate for Minecraft 1.21.1 and NeoForge 21.1.219. The
endpoint is a checked merge into `master`, with signed phase tags and no platform release.

## automated evidence

The editor package is built from `editor-ui` with the pinned Vite, React, and TypeScript versions.
The Access tab covers ownership inheritance, personal and team overrides, server scope, LuckPerms
inbound and outbound rows, synchronized and permanent retention, context maps, command descendants,
and all four direct interaction types. Pure helper tests cover source preserving ownership,
LuckPerms, command, and Selling Bin interaction roundtrips. `npm run check`, `npm test -- --run`,
and `npm run build` pass. The generated `app.js` is the packaged asset served by the authenticated
loopback editor.

The Java suite passes with `./gradlew test build --no-configuration-cache --rerun-tasks`. The
packaged asset checks pass, and the only product version change is `mod_version = 3.0.5` with the
editor package version set to `3.0.5`. Platform pins remain Minecraft 1.21.1, NeoForge 21.1.219,
Java 21, Gradle 8.8, and ModDev 2.0.140.
